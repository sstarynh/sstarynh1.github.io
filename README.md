# Pole Position

Symulator Formuły 1

Gra w przeglądarce: jeden plik `index.html`, bez instalacji.

## Funkcje
- 7 torów w sezonie: Hockenheim, Monako, Silverstone, Spa, Monza, Suzuka, Interlagos
- Tryb kierowcy (gałka i metalowe pedały na telefonie, strzałki/WASD na komputerze) i tryb menedżera (bolid jedzie sam)
- Weekend: FP1–FP3, Q1–Q3, wyścig – każdą sesję można przejechać, zasymulować albo pominąć
- Ustawienia bolidu (11 parametrów) realnie zmieniające czas okrążenia
- Pogoda, 5 mieszanek opon, paliwo, boksy, DRS, Safety Car / VSC, kary, awarie i uszkodzenia
- Telemetria z wykresem prędkości i porównaniem okrążeń
- Kariera: umiejętności kierowców, reputacja, kontrakty, transfery, rozwój bolidu, budżet, statystyki
- Trener Robełt z samouczkiem

## Jak uruchomić
Otwórz `index.html` w przeglądarce.

## GitHub Pages
1. Wrzuć `index.html` do repozytorium.
2. Settings → Pages → Source: *Deploy from a branch*, gałąź `main`, folder `/ (root)`.
3. Gra będzie pod adresem `https://<twoja-nazwa>.github.io/<repozytorium>/`.

Postęp zapisuje się w przeglądarce (localStorage).

Nazwy kierowców i zespołów pochodzą ze stawki F1 2026; oceny i osiągi w grze są wymyślone. Gra nie jest powiązana z Formułą 1 ani z żadnym zespołem.
